How well do research agents answer traders' questions?

This is a set of 110 test questions for comparing Raven with general-purpose AI agents (and future specialist competitors) on the questions crypto and stock-perp traders actually ask.

Every question comes with a list of facts a good answer must get right, where to check each fact, and a simple score: 0, 1 or 2.

All agents get the same question at the same moment, and we check their answers against market data saved at that moment. That keeps the comparison fair even though prices keep moving.

Where the questions come from

40 questions come from real usage. We took questions people asked Raven, cleaned them up and made them reusable. For example, "BTC" becomes a fill-in slot, so the question still works next month.

70 were written to fill gaps. They spread the set evenly across 10 topics and three difficulty levels. Some are deliberate "trick" questions: one with a false premise, one where the data doesn't exist, one that needs an exact time.

First results: a general-purpose agent

As a first test of the benchmark itself, we ran a general-purpose AI agent (no Raven tools, just public data sources and web search) on 40 questions, four from each topic. Raven hasn't been tested yet.

The same agent wrote and graded the answers, strictly, against data saved at the moment each question was asked. Treat these numbers as a rough first look until people have double-checked them.

What we learned

  • Good at simple lookups (price, funding, spread) and spotting false premises.
  • Weak at anything needing a full history of trades: who's buying and how much over the last hour. Public data only shows the last few trades.
  • Honest: it admitted missing data in 20 of 21 cases where it should.

Every graded answer

How answers are scored

Each answer gets 0, 1 or 2:

2
Correct and complete. Every key fact is right, sources and times are given, and missing data is admitted rather than guessed.
1
Partly right. On topic with nothing made up, but something is missing, out of date, or unsourced.
0
Wrong or no answer. A key fact is wrong or made up, a false premise is accepted, or the agent failed or ran out of time.

The checking process

  1. Fill in the blanks. Swap placeholders like {TICKER} for real values, and replace any that have gone stale.
  2. Ask every agent at once. Send each question to all agents at the same moment, and record how long each takes and whether it failed. Each agent gets 4 minutes.
  3. Save the real answer key. Within a minute of sending, pull the true numbers from the original sources: the exchange's own data, SEC filings, official announcements, blockchain explorers and official calendars.
  4. Grade without names. Hide which agent wrote each answer, check each fact against the saved numbers, then give 0, 1 or 2.
  5. Double-check. An AI grader can do the first pass. People re-check a sample of one in five, plus every 0 and every trick question.

How close is "correct"?

Prices count as correct within 0.5% of the saved value. Percent changes are allowed 0.3 points. Official event times must be within a minute, using the time the source published it, not when a news channel reposted it. Each question lists its own allowance.

Also tracked for every run

Did it cite sources? Did it give times? Did it admit missing data? Did it keep track of earlier messages in the conversation? How often did agents fail or time out? How long did a typical answer take, and how long did the slowest one in ten take?

How this fits the Eval Desk

The Eval Desk gives each answer a 0–100 quality score from seven weighted ratings (usefulness, trading relevance, unique information, evidence, honesty about uncertainty, answering the question, clarity). Anything flagged as a serious error is capped at 40.

We treat every "automatic zero" item as a serious error, so the two scores line up. Roughly, a 2 here is a desk score of 75 or more, and a 0 is 40 or less. The questions can be imported into the desk 50 at a time.

What's still missing

Known gaps

  • The fact checklists are first drafts and haven't been tested on real runs.
  • Some example values will go out of date and need swapping.
  • Only 17 of the 100 questions are easy.
  • General AI agents can't set alerts, so those questions mostly test whether an agent is honest about that.
  • The usage logs are small: 172 conversations.

Next steps
